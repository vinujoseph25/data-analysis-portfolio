# Data Analysis Portfolio

A public portfolio of practical data analysis and machine learning projects.

## Projects

### 1. Black Friday Sales Prediction

A regression project using the Kaggle Black Friday sales dataset to understand customer purchase behaviour and predict `Purchase` values.

- Dataset: Kaggle Black Friday Dataset
- Problem type: Supervised regression
- Target: `Purchase`
- Primary model: Multivariable Linear Regression
- Evaluation: R², adjusted R², MAE, MSE and RMSE
- Main tools: Python, pandas, NumPy, matplotlib, scikit-learn and statsmodels

See [`projects/black-friday-sales-prediction/README.md`](projects/black-friday-sales-prediction/README.md) for the project documentation.
